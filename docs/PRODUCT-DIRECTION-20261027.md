## 同一个交付目标

网络强制代理、宿主敏感信息隔离、正常开发工具与子进程能力、授权NVIDIA GPU计算，以及安装/恢复/GUI属于同一产品。任何一部分通过，都不能把整体标记DELIVERABLE。真实Claude登录/推理/正式会话继续DEFERRED_BY_USER；先以工具自有合成工作负载取得网络、权限和兼容性证据。

可信管理侧可审核代理身份和必要状态；开发侧只取得具体工作区、工具链、网络通道和设备授权。不能从“允许用代理”推导读取FlClash配置/节点/订阅/管理接口的权限；不能从“允许PowerShell/Python/Git/GPU”推导整个用户账户或宿主进程访问权。

## 十四项环境体检及强制准入

每项结果必须包含状态、当前依据/时间、适用性、失败原因、修复建议、是否为该策略必要条件。以下全部为必需交付项，当前尚未形成完整强制门禁：

| 项目 | 合格条件需要表达的内容；不得替代的证据 |
|---|---|
| 代理内核 | 实际进程/监听身份及通道可用；不能按名称存在即通过 |
| TUN网卡 | 当前策略对TUN的真实依赖及接口状态；WFP契约可明确说明不适用，不为绿灯修改全机 |
| 出口IP | 通过授权通道的有界观测及用户策略；不是物理防直连证明 |
| IP一致性 | 明确比较哪些通道/时间/会话，保留漂移事实；不能把历史变化等同泄漏 |
| 时区 | 用户选定目标与实际状态；不按IP位置自动改时区 |
| 地区Locale | 明确目标、实际值和影响；与操作系统隔离分别判断 |
| IPv6 | 受保护身份的实际阻断及负向行为；不以全机关闭作为默认前提 |
| DNS | 原始DNS及可能经系统服务代理的解析分别评估；无响应不是阻断证明 |
| WebRTC | 对当前组件适用的UDP/STUN/浏览器路径与限制；不把CLI结果推广到共享浏览器 |
| 保镖守护进程 | 真实本会话归属/存活/接管与故障行为；仅PID或绿色报告不够 |
| 路由规则 | 实际运行规则、目标会话和网络行为一致；配置文件存在不够 |
| 客户端语言 | 明确用户策略和当前组件语言；不冒充网络隔离证明 |
| ASN属性 | 来源、当前出口和用户选择的环境策略；ASN类别不天然证明安全/泄漏 |
| Claude生态可达性 | 必要服务经授权通道的TLS/HTTP观测；不把401/403解释为账号已授权，不启动真实会话 |

严格全项策略必须使14项都满足明确合格条件。FAIL、UNKNOWN、超时、不可信或过期不能放行；不适用必须由明确场景/策略和当下安全契约支持，不能把未知重写成不适用。环境一致性条件与不可豁免的系统安全条件分开展示，严格策略可将前者也设为必要条件。

真正授权位于可信Broker/生命周期所有者。GUI、日常CLI、快捷方式和直接调用不能各自拥有绕过门禁的启动路径。许可需绑定当前策略摘要、目标组件/镜像、工作区/工具/设备授权、安装版本、实际token/Job/WFP和本次会话；创建前和首次执行前重新核对必要实时状态。历史PASS或GUI缓存不是永久许可。运行期间的持久屏障、Watchdog及恢复继续保持。

现有固定qualification命令只运行安装包内的有限合成程序，不接受任意可执行文件、脚本或Claude目标，不能被复用成正式开发会话的门禁旁路。

## 系统安全准入与资源边界

除十四项外，必须验证安装资产/可信管理侧完整性、AppContainer或实际原生身份、Job原子归属、当前WFP、子进程继承、授权项目/工具/设备可用性，以及对未授权目录、注册表、管理接口和敏感进程对象的实际拒绝。允许项目读写和编译/测试/依赖下载，也要用同一工具调用链尝试越权，不能只证明“工具能运行”。

当前直接127.0.0.1:7890仍是有限代理资格基线，不能视为敏感信息隔离已完成。正式开发侧的网络能力需要收窄：防止经允许代理请求宿主/私网管理端点、代理配置/管理功能或DNS重绑定路径；必要的本地MCP/开发服务通过具体授权表达。可采用可信转发/网关等原生组合，不能只封9090后假定无法经代理绕回。没有完成这项边界前，不把现有代理资格入口升级成真实Claude通用启动入口。

受保护工具子进程必须保持权限边界；独立后台组件需要单独可信纳入，名称匹配和初始进程树都不是完整归属。Desktop、MCP/Hooks、CLI工具及共享浏览器分别标支持范围；不限制整个共享浏览器以替代标签页隔离。系统/设备元数据和侧信道另列边界，不作绝对隐藏承诺。
