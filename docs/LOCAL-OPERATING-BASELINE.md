## 设计约束

- 把用户既有 FlClash 全局/TUN 网络作为外部依赖，保护工具只在自己所属 Claude 会话范围内叠加限制。
- 用户日常代理模式属于用户选择。Global 是常态，不授权程序强制切换模式或节点；用户偶尔选择其他模式也不应被偷偷改回。
- 研发测试在专用临时身份和探针范围内进行。关闭 FlClash、TUN 或修改真实 Claude 的规则仍需单独明确授权。
- 系统代理同时检查普通配置、WinHTTP IE 配置、WinINet 每连接配置；检查其是否一致，以及 HTTP/HTTPS 是否指向本机已验证的 FlClash 入口。
- 接受 FlClash 常见的裸地址和按 HTTP/HTTPS 分开的表示形式，不为了满足文本格式而重写用户设置。
- 实验前后与运行期间检查系统代理指纹。发现漂移，停止自己所属的探针并清理临时项，记录差异；不自动重置全局网络。

## 证据解释

在 TUN/全局代理开启时，使用普通 TCP 套接字连接公网 IP 也可能被 FlClash 接管，因此该连接成功不等于物理网卡真实直连。

已有 IPv4 防火墙探针只能证明其已测路径在加规则前连接成功、加规则后明确 AccessDenied；不能从该结果倒推出所有真实直连路径已经被覆盖。

全局代理正常、主程序 TCP 被阻断、子进程 TCP 被阻断、只允许指定回环代理端口、UDP 投递证据、系统 DNS 归属，以及真实代理故障，应分别记录，不能相互替代。尚未覆盖的领域保持 UNKNOWN。

## 当前约束状态

真实 Claude 的保护启动仍未放行。现有两条 Claude 防火墙规则保持禁用。临时 AppContainer/WFP 探针的通过项只属于对应专用探针版本和本机条件，不授予实际 Claude 的部署资格。

## 管理员执行授权与打扰控制

当时用户授权限定管理员工作且要求不影响日常使用。同一未消耗且范围未变的具体授权不反复确认，
但该历史段落不构成今天通用管理员许可，也不能复活已消耗授权；新高影响操作按现行规则审查，UAC仍由本人确认。

尽量把同一工作包的管理员步骤合并到一次有明确范围和结束条件的执行批次；终端及后台辅助窗口保持隐藏，编译、只读检查和普通用户测试使用普通权限。不得为减少提示而关闭 UAC、自动点击安全桌面的提权提示，或创建不受限的长期管理员命令入口。

关闭真实 FlClash/TUN 会影响用户日常全局网络，仍不属于当前允许的无打扰实验。优先使用临时探针和其独立测试路径进行故障模拟。

## 真实 Claude 启动延期

用户明确目前没有 Claude 账号登录计划，也不需要正式启动 Claude。本阶段默认只提供保护工具与检查/维护功能，不启动真实 CLI、不引导登录、不执行模型推理；真实会话验收记录为用户要求延期，不能用探针结果替代。
