日期：2026-10-25。用户最新观察：已清除、未重启、卡巴斯基显示正常；用户选择继续使用本机。VM 不是前提。当前阶段只推进源码和纯文本验证，不编译或启动项目程序。此计划不自动移除现有停止条件，不能用“安全软件未再弹窗”证明误报或系统安全。

## 必须先补齐的管理员代码与状态边界

现有开发租约会从用户可写项目路径提升 PowerShell，并运行同路径 helper、写入用户可写证据；不能直接包装成正式安装器。调用协议整改后，新增独立生命周期 Library 的包授权、句柄/ACL 核验、受保护状态、暂存和阶段账本源码；尚未编译、接入或执行。bootstrap、实际 broker/owner、完整生命周期 handlers 与恢复仍未完成。见 [源码内核](SECURE-LIFECYCLE-SOURCE.md)。以下要求不能因新增源码就计作交付通过。

- 生产管理员组件必须由明确可信的安装包引导，复制到受保护的固定安装目录；验证包来源、版本和完整性，不能把用户可改的 manifest/hash 当信任根。首次引导、签名/发布身份与更新信任策略须有明确可审查方案。
- 安装代码与管理员状态分离。对所有祖先、目录、文件及实际打开句柄核对最终路径、重解析点、所有者和有效可写权限；普通用户不能替换管理员执行组件或恢复日志。只记录执行前 hash 不够。
- 协议只接受固定操作和受约束的 run/package/GUID；不接受命令、脚本、DLL、任意路径、URL、任意 SID 或任意参数。代理端点绑定项目已验证范围，不能泛化成管理员网络修改接口。
- 管理员变更记录存可信状态边界，先落恢复身份再变更；普通用户只读导出的脱敏报告。恢复依据管理员记录与实时对象交叉核验，拒绝只凭调用者提供的计划删除对象。
- 不为减少 UAC 提示创建长期任意命令入口；同工作包合批，所有 Windows UAC 由本人确认。正式产品默认未激活，真实 Claude 规则保持禁用。
- 安装/更新使用明确版本和状态机：预检→准备→验证→激活或回滚。更新不能覆盖活动会话依赖；卸载先终止工具拥有的会话，精确移除拥有对象，保留原配置/备份/失败证据；任一清理未证实则报未完成，不扫描式删除、不导入整份旧防火墙备份。

这些要求需要源码实现与负向验收，尚不能把设计文档计作交付完成。

S1-S5 均未执行。它们不是一次性全套自检；每阶段必须按实际范围审查已有证据，再执行缺失路径。现有管理员操作授权沿用，不重复索取同一聊天授权；程序不自动点击 UAC。需要改变已声明静态阶段时，先具体记录该阶段源码与停止条件，不能只删停止脚本重跑。

## 全阶段停止与不变量

卡巴斯基保持开启；再次告警立即停止项目运行和后续构建/试验，保留原事件与当次完整工件身份，不使用排除、恢复原文件、改名、重打包或关闭防护重试。网络漂移或日常访问异常时先停止本工具拥有的实验并精确清理，记录失败；不自动重置全局代理。

不得停止/重启 FlClash、TUN、BFE，不切节点/模式，不全局重置网络或关闭 IPv6。只模拟工具会话/专用探针的故障；实际 BFE/系统重启覆盖仍 UNKNOWN，未来如需要另行制定与用户日常使用相容的范围。此次不要求重启。

真实 Claude 登录、认证资料读取、推理与正式启动一直 DEFERRED_BY_USER。DNS broker、任意子工具/MCP、共享浏览器和公网 UDP/STUN 不能由局部回环探针推导为通过。配置修复只能普通权限、三个字段、私有原始字节备份，后续用户修改必须拒绝覆盖；路径/句柄与回执绑定缺口仍须实现。
