EXPECTED_BYTES仅表示本次读取的实际字节等于私有stage intent中的预期摘要/长度（固定身份元数据则与生成器产生的固定字节比较）。它不是包批准、运行成功或AV兼容性结论；读取完成回执时若存在矛盾、截断、不可读或替换仍拒绝。

OWNED_PENDING用于零字节或受界限约束的未完成写入。归属与字节状态来自同一实际文件句柄：owner/DACL、最终路径、非重解析、单硬链接、卷/对象ID及非继承创建标记都须核对，标记还须匹配原install/update操作、持久begin记录、固定角色/release和私有完整资产清单。文件长度不能超过该资产声明长度；manifest上限为64KiB；两种固定marker上限是生成器字节长度。

随后必须同时满足：原操作仍处于planned；对应完成回执确实不存在；该release没有release/restage/selection发布记录，也不是current指向。代码根marker影响整个安装，要求本安装没有任何发布/选择记录或current。未发布检查严格读取所有匹配名称的记录，格式/身份异常、无法读取或容量超界都拒绝，不能悄悄跳过；每个前缀上限8192条。状态操作锁和运行期关闭/零进程前置条件仍适用，不防恶意管理员或已受控bootstrap。

已存在完成回执时，当前对象ID、标记、长度、摘要和BYTES_VERIFIED状态必须全部匹配；即使包中的预期字节相同，换了对象也拒绝。发布过的文件出现截断或不同字节不能降级为pending。符合预期字节但完成回执尚未落盘的窗口，只记录EXPECTED_BYTES；仍不生成完成/发布回执。
