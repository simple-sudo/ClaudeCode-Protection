# 保护中心项目操作流程

当前SOURCE / INTEGRATED，六产品非执行语义检查通过；尚未构建或安装本轮GUI/相对目录修补。
实际安装仍42f/9172/7DDC/GUI934E，已通过的原9F07用户项目和封存/28次真实拒绝继续复用。

新增“选择 C# 项目”“导入项目任务包”“开始项目开发”。用户选择含cpc-project.json的文件夹，
只读取其中声明的C#源文件与清单，不扫描整个目录；有其他输入数据时可以导入完整任务包。
界面显示源码、精确修改前后文字、运行/测试入口和预期测试数。选择只准备不可变字节，
不会执行代码或触发UAC。清单读取与文件捕获之间若发生清单变化则拒绝。

点击开始后选择保存位置，工具在其中创建唯一新运行目录并写入已审阅快照。新目录先规划
后写入，使任何写入失败都能在界面显示可能留下部分文件的位置。输入摘要与完整NTFS路径
在普通客户端生命周期持有，防止审阅后替换将运行的代码。开发位置必须是当前正常安装
布局中的GUI exe/dll；不支持开发目录或dotnet加载GUI来触发安装任务。

项目专用后端只调用持有字节/权限校验的安装daily workspace-build-csharp；普通维护命令
白名单不扩大为任意命令。清理继承环境，使用固定系统运行时。原客户端自己发起本人UAC，
原Broker/Job/LPAC/输入/执行前封存/成功清理导出不变；无GUI自建执行器、直接Broker通道或
绕过当前安装/人工作用域。每次普通调用180秒含UAC、输出1秒drain，最多64Ki字符输出和
16Ki字符错误。仅句柄/创建时间/映像绑定的本次普通客户端可在异常时停止，不终止提升owner
或树，不从客户端退出推定Job闭合，不自动重试/恢复。

GUI仅接受本次持有客户端返回的严格C#项目成功报告，核对基线/结果摘要、原owner封存标记、
两actor成对拒绝、无网络/正式准入、实际文件变化和完整CSharpProjectTask结果。磁盘上的
普通JSON报告本身不是保护证明。核验后的不可变结果提取到本次目录下files，不执行DLL、
不合并或覆盖原项目；输入/结果文件后来改变也不会改变已审阅恢复内容。
取消1223、超时、非零、报告/恢复失败均保留目录并说明未确认完成；保存诊断失败不能掩盖
已返回的操作结果。界面单操作串行，忙时延迟关闭，任务未准备时不启用开始按钮。

本轮还标记daily的UAC启动失败阶段为固定UAC_START，不改变原Win32错误；用于区分启动环节，
不根据错误码指认人为取消或AV原因。C#工具在原身份/封存门之后临时进入复制的项目目录，
运行/测试结束恢复原目录，使相对源码/数据访问符合项目语义。此修改不扩大目录权限；新增
普通示例检查src/Counter.cs相对存在性，旧已实测9F07字节和失败记录保持原样。

GUI完整窗口交互/实际UAC、相对目录修补的受保护资格和新安装仍未完成。当前受保护验收
来自原42f项目案例；网络/十四可信准入/GPU/其他宿主资源/PowerShell/恢复及完整产品保持开放。
