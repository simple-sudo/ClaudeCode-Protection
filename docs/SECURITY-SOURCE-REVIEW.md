## 本轮已修正的源码缺口

`src/NativeFence/FenceOwnership.h` 的 `delete_owned` 原先在开启删除事务前调用 `validate_owned`，核验与删除之间存在状态变化窗口。现把全部归属核验放进同一写事务，并继续保证“全部核验成功后才开始逐项删除”；任何核验或删除异常均走事务中止。
